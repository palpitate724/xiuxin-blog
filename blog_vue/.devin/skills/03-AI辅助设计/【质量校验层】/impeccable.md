# Impeccable Skill

设计质量审计技能，提供全面的设计质量检查和优化建议。

## 审计维度

### 1. 视觉层次
- **焦点清晰**: 主要操作是否突出
- **信息架构**: 信息组织是否合理
- **视觉权重**: 元素重要性是否明确
- **引导路径**: 用户视线是否自然流动

### 2. 可用性
- **可发现性**: 功能是否易于发现
- **可理解性**: 界面是否易于理解
- **可操作性**: 操作是否易于执行
- **容错性**: 错误是否易于恢复

### 3. 一致性
- **视觉一致**: 设计元素是否统一
- **交互一致**: 交互模式是否统一
- **内容一致**: 内容表达是否统一
- **品牌一致**: 品牌形象是否统一

### 4. 可访问性
- **键盘导航**: 是否支持键盘操作
- **屏幕阅读器**: 是否支持辅助技术
- **色彩对比**: 色彩对比是否达标
- **字体大小**: 字体大小是否合适

## 审计流程

### 阶段 1: 快速扫描
```
时间: 5-10 分钟
目标: 发现明显问题

检查项:
- 整体布局是否合理
- 色彩是否和谐
- 字体是否易读
- 交互是否流畅
```

### 阶段 2: 详细分析
```
时间: 30-60 分钟
目标: 深入分析问题

检查项:
- 每个页面的布局
- 每个组件的设计
- 每个交互的状态
- 每个文本的表达
```

### 阶段 3: 用户视角
```
时间: 15-30 分钟
目标: 模拟用户使用

检查项:
- 用户是否能完成任务
- 用户是否会遇到困惑
- 用户是否会感到挫败
- 用户是否会留下好印象
```

### 阶段 4: 优化建议
```
时间: 30-60 分钟
目标: 提供具体建议

检查项:
- 优先级排序
- 具体改进方案
- 实施难度评估
- 预期效果分析
```

## 常见问题诊断

### 布局问题

#### 问题 1: 信息过载
```
症状:
- 页面元素过多
- 信息密度过高
- 用户注意力分散

解决方案:
- 减少次要信息
- 增加留白空间
- 建立信息层级
- 分页展示内容
```

#### 问题 2: 对齐混乱
```
症状:
- 元素对齐不统一
- 间距大小不一致
- 视觉感觉混乱

解决方案:
- 统一对齐方式
- 建立间距系统
- 使用网格系统
- 保持视觉秩序
```

### 色彩问题

#### 问题 1: 色彩冲突
```
症状:
- 色彩过多
- 对比不当
- 视觉疲劳

解决方案:
- 减少色彩数量
- 使用统一色板
- 调整色彩对比
- 考虑无障碍性
```

#### 问题 2: 品牌不一致
```
症状:
- 色彩偏离品牌
- 风格不统一
- 品牌识别度低

解决方案:
- 遵循品牌指南
- 使用品牌色彩
- 保持风格统一
- 强化品牌识别
```

### 排版问题

#### 问题 1: 字体层级不清
```
症状:
- 字体大小相近
- 层级关系不明
- 信息重点不清

解决方案:
- 建立字体层级
- 扩大字体差异
- 使用字重变化
- 增加间距对比
```

#### 问题 2: 可读性差
```
症状:
- 字体过小
- 行高过密
- 对比度不足

解决方案:
- 增大字体大小
- 调整行高间距
- 提高色彩对比
- 选择易读字体
```

### 交互问题

#### 问题 1: 反馈不足
```
症状:
- 操作无反馈
- 状态不明确
- 用户不确定

解决方案:
- 添加操作反馈
- 明确状态显示
- 提供确认提示
- 增加微交互
```

#### 问题 2: 交互不一致
```
症状:
- 相似操作不同
- 交互模式混乱
- 学习成本高

解决方案:
- 统一交互模式
- 遵循平台规范
- 减少学习成本
- 提供操作引导
```
