# Frontend Design Skill

前端设计方向锚定技能，帮助确定项目的设计美学方向。

## 设计方向评估

### 风格维度分析

#### 1. 视觉风格
- **极简主义**: 简洁、留白、聚焦内容
- **现代扁平**: 去除拟物化，强调色彩和排版
- **玻璃拟态**: 半透明、模糊背景、层次感
- **新拟态**: 柔和阴影、凸起凹陷效果
- **粗野主义**: 原始、大胆、高对比度
- **Bento Grid**: 网格布局、模块化设计

#### 2. 色彩策略
- **单色系**: 同色相、不同明度饱和度
- **类比色**: 相邻色相、和谐统一
- **互补色**: 对比强烈、视觉冲击
- **三角色**: 三角关系、平衡协调
- **渐变色**: 流动过渡、现代感强

#### 3. 排版风格
- **瑞士风格**: 网格系统、无衬线字体
- **现代主义**: 简洁字体、大胆排版
- **手写风格**: 个性化、温暖亲切
- **科技风格**: 等宽字体、数据感强

### 品牌定位分析

#### 企业级应用
- **特点**: 专业、稳定、高效
- **推荐**: 极简主义、单色系、瑞士风格
- **字体**: Inter、Roboto、SF Pro

#### 消费级应用
- **特点**: 友好、直观、易用
- **推荐**: 现代扁平、类比色、现代主义
- **字体**: Poppins、Nunito、Quicksand

#### 创意类应用
- **特点**: 个性、创新、视觉冲击
- **推荐**: 玻璃拟态、渐变色、Bento Grid
- **字体**: Montserrat、Oswald、Playfair

#### 工具类应用
- **特点**: 实用、清晰、高效
- **推荐**: 极简主义、单色系、科技风格
- **字体**: JetBrains Mono、Fira Code、Source Code Pro

## 设计方向选择流程

### Step 1: 项目分析
```
1. 项目类型 (B2B/B2C/工具/创意)
2. 目标用户画像
3. 品牌调性定位
4. 功能复杂度
5. 内容密度
```

### Step 2: 风格匹配
```
根据项目分析结果，匹配最适合的设计风格：
- 企业级 → 极简主义 + 瑞士风格
- 消费级 → 现代扁平 + 现代主义
- 创意类 → 玻璃拟态 + Bento Grid
- 工具类 → 极简主义 + 科技风格
```

### Step 3: 细节定制
```
1. 确定主色调和辅助色
2. 选择字体系统
3. 定义间距规则
4. 设定圆角规范
5. 确定阴影层次
```

## 设计方向锚定示例

### 示例 1: 企业级管理后台
```
项目类型: B2B 管理系统
目标用户: 企业管理员
品牌调性: 专业、高效、稳定

设计方向:
- 视觉风格: 极简主义
- 色彩策略: 单色系 (蓝色主调)
- 排版风格: 瑞士风格
- 字体选择: Inter
- 间距规则: 8px 基准
- 圆角规范: 4px
- 阴影层次: 微妙阴影
```

### 示例 2: 消费级社交应用
```
项目类型: B2C 社交应用
目标用户: 年轻用户
品牌调性: 友好、活泼、现代

设计方向:
- 视觉风格: 现代扁平
- 色彩策略: 类比色 (橙色调)
- 排版风格: 现代主义
- 字体选择: Poppins
- 间距规则: 4px 基准
- 圆角规范: 12px
- 阴影层次: 柔和阴影
```

### 示例 3: 创意类设计工具
```
项目类型: 创意设计工具
目标用户: 设计师、创作者
品牌调性: 创新、个性、视觉冲击

设计方向:
- 视觉风格: 玻璃拟态 + Bento Grid
- 色彩策略: 渐变色 (紫蓝渐变)
- 排版风格: 现代主义
- 字体选择: Montserrat
- 间距规则: 8px 基准
- 圆角规范: 16px
- 阴影层次: 强烈阴影
```
