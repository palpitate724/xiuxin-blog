# Taste Skill

审美判断力注入技能，帮助 AI 理解和应用设计美学原则。

## 审美维度

### 1. 视觉平衡
- **对称平衡**: 左右对称、上下对称
- **不对称平衡**: 通过元素权重实现平衡
- **径向平衡**: 从中心向外辐射
- **网格平衡**: 基于网格系统

### 2. 对比与层次
- **大小对比**: 大小差异创造焦点
- **颜色对比**: 色彩对比突出重点
- **字体对比**: 字体大小、粗细对比
- **空间对比**: 留白与内容的对比

### 3. 节奏与重复
- **重复模式**: 元素规律性重复
- **交替模式**: 元素交替出现
- **渐进模式**: 元素渐进变化
- **随机模式**: 控制的随机性

### 4. 统一与多样性
- **色彩统一**: 统一的色彩系统
- **字体统一**: 统一的字体规范
- **风格统一**: 统一的设计语言
- **适度多样**: 避免单调

## 审美判断原则

### 美学评分标准

#### 布局评分 (40%)
- 对齐是否工整
- 间距是否均匀
- 层次是否清晰
- 焦点是否突出

#### 色彩评分 (30%)
- 色彩是否和谐
- 对比是否恰当
- 品牌是否一致
- 无障碍是否考虑

#### 排版评分 (20%)
- 字体是否易读
- 层级是否分明
- 间距是否合理
- 风格是否统一

#### 细节评分 (10%)
- 图标是否精致
- 动效是否流畅
- 状态是否完整
- 边界是否清晰

### 审美提升建议

#### 常见问题诊断
1. **视觉混乱**
   - 原因: 元素过多、缺乏层次
   - 解决: 减少元素、增加留白、建立层级

2. **色彩冲突**
   - 原因: 色彩过多、对比不当
   - 解决: 减少色彩、调整对比、使用色板

3. **排版混乱**
   - 原因: 字体过多、大小不一
   - 解决: 统一字体、规范字号、建立层级

4. **细节粗糙**
   - 原因: 图标不统一、状态不完整
   - 解决: 统一图标、完善状态、优化细节

## 审美训练示例

### 示例 1: 卡片设计优化

#### 优化前
```
问题:
- 间距不均匀
- 字体层级不清
- 阴影过重
- 缺少视觉焦点
```

#### 优化后
```
改进:
- 统一间距 (8px 基准)
- 建立字体层级 (标题/正文/辅助)
- 调整阴影 (微妙层次)
- 增加视觉焦点 (主按钮)
```

### 示例 2: 表单设计优化

#### 优化前
```
问题:
- 标签对齐不统一
- 输入框样式不一致
- 错误提示不明显
- 按钮权重不明确
```

#### 优化后
```
改进:
- 统一标签对齐 (右对齐)
- 统一输入框样式
- 明显错误提示 (红色+图标)
- 明确按钮权重 (主/次按钮)
```

### 示例 3: 列表设计优化

#### 优化前
```
问题:
- 行高不一致
- 信息密度过高
- 缺少视觉分隔
- 操作按钮不明显
```

#### 优化后
```
改进:
- 统一行高 (1.5倍)
- 降低信息密度
- 增加分隔线
- 突出操作按钮
```

## 审美应用流程

### 1. 快速评估
```
5秒快速扫描:
- 第一印象如何？
- 视觉焦点在哪里？
- 有明显的问题吗？
```

### 2. 详细分析
```
按维度分析:
- 布局: 对齐、间距、层次
- 色彩: 和谐、对比、品牌
- 排版: 易读、层级、统一
- 细节: 图标、动效、状态
```

### 3. 优化建议
```
优先级排序:
- 高优先级: 影响核心体验
- 中优先级: 影响视觉质量
- 低优先级: 影响细节完善
```

### 4. 持续改进
```
迭代优化:
- 实施高优先级改进
- 收集用户反馈
- 继续优化中低优先级
```

## 审美案例库

### 优秀案例参考
- **Apple**: 极简主义、完美细节
- **Stripe**: 现代设计、微妙动效
- **Linear**: 高对比度、精致交互
- **Notion**: 简洁实用、信息清晰
- **Figma**: 专业工具、视觉友好

### 避免的反面案例
- 过度装饰、视觉混乱
- 色彩冲突、对比不当
- 排版混乱、层级不清
- 细节粗糙、状态缺失
- 一致性差、风格不统一
